# Budget Trip Booking

A Django-based trip booking platform for discovering affordable trips, comparing packages, and managing bookings efficiently.

## Features

- User Registration & Login
- Search Trips by Location
- Search Trips by Budget
- View Trip Details
- Trip Booking System
- Payment Page
- Booking Confirmation
- My Bookings Dashboard
- Admin Dashboard
- Trip Management

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Installation

1. Clone the repository
2. Install requirements
3. Run migrations
4. Start the server

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
